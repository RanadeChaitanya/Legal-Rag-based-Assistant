# Legal RAG Assistant (India)

Terminal-first, verifier-first RAG assistant for Indian legal situations
(NI Act s.138, arrest rights under BNSS, FIR refusal, PWDVA 2005).

General legal information only - not legal advice. See DISCLAIMER.md.

## Quick start
1. cp .env.example .env and fill in the keys.
2. pip install -e .[dev]
3. pytest

The emergency gate (emergency/) works fully offline.
